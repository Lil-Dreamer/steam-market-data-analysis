# 🎮 Steam Market & Pricing Strategy Analysis

An end-to-end Data Analytics portfolio project analyzing **~90,000 games on Steam** to uncover market trends, pricing sweet spots, and revenue drivers in the gaming industry.

---

## 🚀 Project Overview
This project explores the economic structure of the Steam marketplace. By combining data processing in Python with an executive-level Power BI dashboard, the analysis answers critical business questions for game developers and publishers regarding pricing, player retention, and genre success.

## 🛠️ Tech Stack
* **Data Processing & Cleaning:** Python (Pandas, NumPy)
* **Data Modeling & Visualization:** Power BI Desktop (DAX, Conditional Formatting, Interactive UI Design)
* **Design System:** Steam-inspired Dark Theme (`#121417` canvas, `#1b1e23` cards, `#5c7e10` / `#a4d007` accents)

---

## 🔍 Key Business Insights

1. **Free-to-Play vs. Paid Dynamics:** 
   While paid titles make up the vast majority of the catalog (~79%), Free-to-Play games capture massive average player bases, serving as top-of-funnel ecosystems for microtransactions.
   
2. **The Revenue Giants (50€+ Bracket):** 
   AAA blockbusters and premium titles dominate total estimated revenues, proving that high upfront production value correlates directly with massive financial returns.

3. **The Pricing Sweet Spot (20€ - 50€):** 
   Games priced between 20€ and 50€ achieve optimal player engagement and retention, representing the most balanced monetization tier for mid-to-high-tier developers.
